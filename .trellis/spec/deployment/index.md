# Deployment Guidelines

OfferMap is built with Vinext/Vite and deployed as a Cloudflare Worker. Runtime behavior is split between App Router code and the Worker entry point.

| Guide | Scope |
|---|---|
| [Vinext and Worker](./vinext-and-worker.md) | Build plugins, request dispatch and image optimization |
| [Environment configuration](./environment-configuration.md) | Public configuration, server secrets and demo mode |
