# Frontend Development Guidelines

> Best practices for frontend development in this project.

---

## Overview

This directory captures the current OfferMap frontend conventions: Vinext/Next App Router pages and API routes, a single client workspace component, Supabase-backed account data, and typed `lib/` domain services.
